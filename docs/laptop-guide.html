Running TAB PMS on your laptop

Set it up once in about 30 minutes, then it starts by itself every morning and backs itself up to OneDrive. Written for Windows 10 or 11. No programming needed: you install three programs and double-click a few files.

What you need

  • A Windows 10 or 11 laptop with at least 8 GB of memory and 5 GB of free space.
  • Administrator rights on the laptop (to install programs).
  • Your GitHub sign-in (the system's code is in your private repository moeedmangla-ops/tab-pms).
  • OneDrive signed in to your company account, for the daily backups.

One-time setup

Install three programs

Download and install each with the default options.

  • Node.js 22 LTS: nodejs.org. Choose the LTS button.
  • PostgreSQL 16: postgresql.org/download/windows, then "Download the installer". Keep port 5432. When it asks for a password for the database superuser, choose one and write it down; you need it once in step 3. At the end, untick "Stack Builder".
  • Git: git-scm.com/download/win.

Restart the laptop afterwards.

Download the system

Open the Start menu, type PowerShell, and open it. Paste these two lines (right-click pastes), pressing Enter after each:

cd $HOME\Documents
git clone https://github.com/moeedmangla-ops/tab-pms

A browser window asks you to sign in to GitHub; approve it. You now have a folder Documents\tab-pms. Everything below happens inside its windows folder.

Run the setup

In File Explorer open Documents\tab-pms\windows and double-click setup.bat. If Windows shows "Windows protected your PC", click More info, then Run anyway. It asks a few questions:

Password for the 'postgres' user
The one you wrote down in step 1
Load the 20 demo clients?
Y to look around with sample data, N to start clean for real work
Your email address (if N)
You become the administrator
Administrator password (if N)
12 characters or more

It then installs and builds for 5 to 10 minutes. It's finished when you see Setup complete in green.

Start it and sign in

Double-click start.bat. Two small windows open in the taskbar (the web app and the reminders), then your browser opens http://localhost:3000.

  • Demo: sign in as mp@tabconsultants.test, password TabDemo!2026.
  • Clean start: your email and the password you chose.

The first time, a QR code appears. Open Microsoft Authenticator on your phone, tap +, add an account, scan it, and type the 6-digit code. Bookmark the page.

Make it automatic

Double-click autostart.bat once. From then on:

  • TAB PMS starts by itself every time you sign in to Windows.
  • The database is backed up every day at 13:00 to OneDrive\TAB-PMS-Backups, and the last 30 days are kept. If the laptop was off at 13:00, the backup runs when it next starts.
  • The laptop no longer goes to sleep while plugged in, so reminders keep running.
That's the setup done. The operating guide explains how to use the system day to day: roles, deadlines, clients and leads.

Letting colleagues in the office use it

  1. On your laptop, open PowerShell and type ipconfig. Note the IPv4 Address, for example 192.168.1.25.
  2. The first time a colleague connects, Windows asks whether to allow Node.js on the network. Choose Private networks only.
  3. Give colleagues the address http://192.168.1.25:3000. They must be on the office Wi-Fi.
  4. Add each person in the system under Settings → Users with the right role. Each sets up their own two-factor at first sign-in.
The laptop's address can change when it reconnects to Wi-Fi. If colleagues suddenly can't connect, run ipconfig again. Your IT person can fix the address permanently with a "DHCP reservation" on the office router.

Backups and restoring

Backups land in OneDrive\TAB-PMS-Backups as files named tab_pms_2026-11-16_1300.dump. Each one holds everything: clients, deadlines, history, users, settings. Because they're in OneDrive they are also off the laptop, which is the point.

To restore (laptop lost, data entered by mistake, or moving to a new machine):

  1. On the new or repaired laptop, do steps 1 to 3 of the setup.
  2. Double-click stop.bat, then restore.bat. Pick a backup from the list and type RESTORE to confirm.
  3. Double-click start.bat. Everyone signs in as before.

Moving later to an office PC or a hosted server works the same way: one backup file carries everything.

Switching from the demo to real use

If you installed with demo data and are now ready for real clients:

  1. Double-click stop.bat.
  2. Open SQL Shell (psql) from the Start menu, press Enter through the prompts, type your postgres password, then type DROP DATABASE tab_pms; and press Enter.
  3. Run setup.bat again and answer N to the demo question.
  4. Sign in, then import your client list from Clients → Import.

Email reminders

Out of the box, the laptop version records every reminder inside the system but does not send email. Each obligation lists the reminders it would have sent. To send real emails, your Microsoft 365 administrator registers the application (steps in docs\CONNECTORS.md). You then paste the three values they give you into tab-pms\.env in Notepad, delete the line MAIL_TRANSPORT="console", and run stop.bat then start.bat. In the system, go to Settings → Email, set the sender mailbox and a test address, check a test run, then un-pause.

If something goes wrong

What you seeWhat to do
setup.bat: "Node.js is not installed" or "PostgreSQL was not found"Install it (step 1), restart the laptop, run setup.bat again.
setup.bat: "Could not sign in to PostgreSQL"The postgres password is wrong. If you've forgotten it, uninstall and reinstall PostgreSQL with a new password.
Browser says "This site can't be reached"The system isn't running. Double-click start.bat and wait 15 seconds.
"Can't reach database server"PostgreSQL stopped. Start menu → Services → find postgresql-x64-16 → Start. Set its Startup type to Automatic.
Wrong password too many timesWait 15 minutes, or have the administrator reset it in Settings → Users.
New phone, lost authenticatorThe administrator ticks reset 2FA for you in Settings → Users. You scan a new QR code at the next sign-in.
Port 3000 already in useThe system is probably already running. Run stop.bat, then start.bat.
Red "job failed" banner in the systemSettings → Jobs shows which job and why.

Know the limits

Laptop off = system offNo reminders, escalations or digests go out, and colleagues can't open it. Reminders up to 3 days late are sent when it comes back.
Office network onlyColleagues at home or at client sites can't reach it. Don't open the port to the internet: there is no HTTPS.
One copy of the dataThe daily OneDrive backup is your protection. Check now and then that new files are appearing.

When the team depends on it every day, move it to an always-on office PC or a hosted server. You use the same files and restore your latest backup there.

Files referred to are in Documents\tab-pms\windows. Written for Windows; the scripts have not yet been run on a Windows machine, so send any error message you see and it will be fixed.
